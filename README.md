# IPT-problem---Nuclear Mousetraps (2021)
I computationally model one of the past IPT (International Physics Tournament). The description is the following:

An array of mousetraps and ping-pong balls results in a chain reaction. Construct a model for the macroscopic dynamics of such a system, identifying all relevant parameters, and determine the spatiotemporal behavior of the mousetrap excitation probability, and the threshold mousetrap density for the chain reaction to occur.

Notebook 0:
The foundational dynamics are built from scratch, including different propagation definitions or settings to offer a more personalized experience. All the relevant code for plotting the system is offered as well.

Notebook 1:
All the code defined in Notebook 0 is collapsed onto a line to incorporate one dimensional dynamics as well.

Notebook 2:
Notebook 2 is a pure-markdown notebook that lays out the core mathematical formulas underpinning the whole project. Really useful for understanding what the physical problem actually encompasses.

The Python files contain all of the functions of the associated Notebook and they can be used for storing the code such that it doesn't take as much space, how it is used in other notebooks which is to import cells from previous notebooks, or for whatever other reasons.
